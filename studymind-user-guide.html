Getting Started

Setup

StudyMind needs Python and LM Studio running locally. The setup is one-time — once done, launch is a single double-click.

  1. Install Python 3.10+
    Download from python.org. Check Add to PATH during install. Verify with python --version in a terminal.
  2. Clone or download the repo
    git clone https://github.com/roni-kid/StudyMine.git
cd StudyMine
  3. Create a virtual environment and install dependencies
    # Windows
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
  4. Install and start LM Studio
    Download LM Studio from lmstudio.ai. Load a model (recommended: qwen3-4b or gemma-3-4b), open the Local Server tab, and click Start Server. Default port is 1234.
  5. Run the app
    python app.py
    Your browser opens automatically at http://127.0.0.1:7860. Or just double-click Studymind.bat.
⚠️ Use PyMuPDF==1.25.5 exactly. Version 1.27.x ships a broken sub-package that crashes on startup.

Optional: Scanned PDF Support (Tesseract OCR)

Skip this if your PDFs are text-based. If you have scanned lecture slides or image-only PDFs, install Tesseract from github.com/UB-Mannheim/tesseract/wiki. You don't need to add it to PATH — StudyMind auto-detects it.

Optional: Audio Voice Synthesis (Piper TTS)

The Audio tab always generates a transcript. To get real synthesized voices, install Piper and drop two .onnx voice files into a voices/ folder inside the project directory. Then set the environment variable before launching:

set STUDYMIND_PIPER_BIN=C:\path\to\piper.exe

StudyMind auto-detects voices in the folder. Manual overrides:

set STUDYMIND_PIPER_VOICE_A=C:\path\to\voice_a.onnx
set STUDYMIND_PIPER_VOICE_B=C:\path\to\voice_b.onnx
Getting Started

Your First Session

Here's the fastest path from zero to studying:

  1. Check the Home tab
    The AI Engine card shows whether LM Studio is online and which model is detected. Hit 🔄 Refresh anytime you switch models in LM Studio.
  2. Upload your documents in Library
    Drag and drop — or click the file picker — and hit Add to Library. You'll see a strategy tag like [MEDIUM] appear. That's the adaptive chunking tier chosen for that document.
  3. Set an active document
    Select a document in the radio list and click ✅ Set as Active. The Q&A tab uses your active document by default.
  4. Ask your first question in Q&A
    Type a question and hit Ask. The app retrieves the most relevant chunks from your document and grounds the answer in them — no hallucination about content that isn't there.
  5. Generate a Quiz or Flashcards
    Pick a difficulty, set how many questions or cards you want, and click Generate. Results appear in seconds. Your library persists across sessions — you won't need to re-upload next time.
💡 The embedding model (all-MiniLM-L6-v2, ~90 MB) downloads automatically on first launch. Every launch after that uses the local cache — no internet needed.
Feature Reference

📚 Library

The Library is the foundation of every other tab. Everything you upload here becomes available to Q&A, Quiz, Flashcards, Mindmap, Audio, and Coding.

Supported file types

FormatExtension(s)Notes
PDF.pdfText-based and scanned (OCR) — auto-detected per page
Word.docxParagraphs + tables extracted
PowerPoint.pptxSlide text + speaker notes; slide images ignored
Ebook.epubChapter by chapter — DRM-protected EPUBs cannot be read
Markdown.mdFormatting markers stripped before indexing
Plain text.txtAuto encoding fallback (utf-8 → latin-1 → cp1252)
Source code.py .js .ts .c .cpp .java .html .cssIndentation preserved — used in Coding tab

Large documents

If a document exceeds the per-session word cap, StudyMind automatically splits it into numbered parts (e.g. Lecture Notes [1/3].pdf) and indexes each part separately. No data is lost.

Managing your library

  • Use Set as Active to switch which document Q&A targets by default.
  • Use Remove to delete a document from the session.
  • Use 🔄 Refresh to sync the document selector across all tabs.
  • Library state persists across app restarts via data/library.json.
Feature Reference

💬 Q&A

Ask questions in plain English and get answers grounded in your documents. Uses Retrieval Augmented Generation (RAG) — the app finds the most relevant chunks first, then asks the LLM to answer from them.

Search scope

Toggle between 🔍 Active Document Only and 🌐 All Documents. Use All Documents when your question spans multiple uploaded files.

Math rendering

Equations render automatically. The app runs two passes: one for LaTeX syntax ($x^2$, \frac{}) and a second for plain-text patterns the model writes naturally (x^2 → x², sqrt(x) → √(x), pi → π, -> → →).

ℹ️ Source badges appear below each answer, showing exactly which document chunks the answer came from.
Feature Reference

📝 Quiz

Generates multiple-choice questions (A–D) from your selected documents. Up to 30 questions per session. Click an option to select it — no keyboard shortcut needed. A progress bar and live score pill update as you answer.

How to use

  1. Select documents
    Check one or more documents from the selector at the top of the Quiz tab.
  2. Set difficulty and count
    Choose Easy / Medium / Hard / Difficult and drag the slider to set how many questions.
  3. Generate and answer
    Click Generate Quiz. Select an option, click Submit Answer, then Next Question.
  4. Review results
    After the final question, a results screen shows your score. Use the 📋 After Quiz accordion to retry wrong answers, study missed topics, or export a report.

After Quiz accordion

  • Retry Wrong Answers — loads only the questions you got wrong into a new mini-quiz.
  • Study Missed Topics — shows which topic areas had the most wrong answers.
  • Export Report — saves a Markdown study report to the exports/ folder.
Feature Reference

🃏 Flashcards

Generates question/answer study cards from your documents. Up to 30 cards per session, with deduplication to remove repeats. One card at a time — think of your answer, then reveal it.

Card flow

  • Click 🔄 Reveal to flip the card and see the answer.
  • Click ✅ Got It if you remembered correctly — card advances, score goes up.
  • Click ❌ Missed if you didn't — card is flagged for later review.
  • Click ⬅️ Prev to go back to the previous card.

More Options accordion

  • Study Missed Cards — loads only the cards you missed into a new deck.
  • Hard Cards Only — uses session history to surface your weakest cards across all sessions.
  • Export CSV (Anki) — saves an Anki-compatible CSV to the exports/ folder.
💡 Flashcards work best in short 10–15 minute rounds. The Hard Cards Only mode gets smarter the more sessions you complete — it tracks your history across restarts.
Feature Reference

🗺️ Mindmap

Generates a structured left-to-right study tree from your documents. Branches represent major topics; child rows contain key ideas. A concept-clustering algorithm groups related ideas automatically.

Controls (in-widget toolbar)

  • Expand All — opens all branch lanes.
  • Collapse All — collapses to root + branch titles only.
  • Fit — resets zoom and position to fit the tree in view.
  • + / − — zoom in and out.
  • Export HTML — downloads the mindmap as a standalone HTML file with full controls.
ℹ️ For the best experience with large mindmaps, use the 📂 Open in Browser accordion to download the HTML export and open it in a full browser window.

Optional: Topic override

Leave the Topic field blank to auto-detect from the document title. Or type a specific topic (e.g. "Newton's Laws of Motion") to focus the mindmap on that area.

Feature Reference

🎙️ Audio Overview

Generates a two-host study conversation grounded in your document — like a podcast episode about your notes. Host A and Host B take turns explaining concepts, asking questions, and reinforcing key ideas.

How it works

The app retrieves the most relevant chunks from your document via semantic search, then uses LM Studio to write a structured two-host transcript in stages. The transcript is always generated. Voice synthesis (WAV/MP3) is optional and requires Piper.

Length options

Choose a length from the Length radio — longer overviews retrieve more chunks and produce more dialogue turns. Shorter options are faster to generate.

Exports

  • Transcript saved as a .md file in exports/audio_overviews/.
  • Audio saved as .wav (or .mp3 if ffmpeg is installed).
  • Both files appear as download widgets after generation completes.
⚠️ Audio synthesis requires Piper and .onnx voice files. If Piper is not configured, the transcript still generates and exports cleanly — only the audio file will be missing.
Feature Reference

⚡ Coding

Analyzes source code files uploaded to the Library. Supports .py .js .ts .c .cpp .java .html .css. Two modes: Explain and Ask AI.

How to use

  1. Upload your code file to the Library
    Go to the Library tab and upload your source file as normal. It will appear in the Coding tab's file dropdown.
  2. Select the file and click Load & Preview
    A VS Code-style syntax-highlighted preview appears on the right.
  3. Pick a mode
    Click 🔍 Explain for a structured six-section breakdown, or 💬 Ask AI to ask questions about the code.

Explain mode — 6 sections

  • Summary — what the file does at a high level.
  • Functions — each function's purpose and parameters.
  • Classes — class structure and responsibilities.
  • Logic Flow — how control flows through the code.
  • Issues — potential bugs or code smells flagged by the model.
  • Test Suggestions — recommended unit test scenarios.

Ask AI mode

Ask any question about the loaded file. The full code is injected as context. Recent chat history is included so follow-up questions work naturally.

💡 Tips & Tricks

🔄
Switch models mid-session
Swap the model in LM Studio, then hit 🔄 Refresh on the Home tab. StudyMind re-detects the context window and updates adaptive chunking.
📦
Upload multiple files at once
Hold Ctrl while selecting files in the Library uploader to add multiple documents in one go.
🌐
Cross-document Q&A
Switch Q&A scope to All Documents to pull answers from your entire library simultaneously — useful when studying across multiple topics.
🔥
Hard Cards Only
After a few flashcard sessions, the Hard Cards Only mode surfaces only the cards you've historically missed. Gets smarter over time.
🗺️
Mindmap before Q&A
Generate a mindmap first to get a topic overview, then use Q&A to drill into specific areas. Mindmap → Q&A is a powerful study sequence.
⚡
Model speed vs quality
Use qwen3-4b or gemma-3-4b for fast day-to-day use. Switch to an 8B+ model only when you need richer, more detailed answers.
📤
Export to Anki
Export flashcards as a CSV from the 📋 More Options accordion. Import directly into Anki for spaced repetition.
🖨️
Scanned lecture slides
With Tesseract installed, StudyMind automatically detects and OCR-processes scanned pages. No extra steps needed — just upload the PDF.

🔧 Troubleshooting

LM Studio is offline — generation buttons do nothing

Open LM Studio, confirm a model is loaded, and click Start Server on the Local Server tab. Then hit 🔄 Refresh in StudyMind's Home tab.

Responses are slow or timing out

Switch to a smaller, faster model in LM Studio (qwen3-4b or gemma-3-4b are recommended). Models larger than 8B require a GPU to run at usable speed.

App crashes on startup with a "static/" directory error

You have the wrong version of PyMuPDF installed. Run:

pip install PyMuPDF==1.25.5

Scanned PDF shows no text

Tesseract is not installed or not detected. Download and install it from github.com/UB-Mannheim/tesseract/wiki — no PATH setup needed, StudyMind auto-detects at the four standard Windows locations.

Audio tab generates a transcript but no audio file

Piper is not configured. Set STUDYMIND_PIPER_BIN to point to your piper.exe and ensure at least one .onnx voice file is in the voices/ folder.

Terminal shows: "UNEXPECTED key: embeddings.position_ids"

This is a harmless warning from the sentence-transformers library. It does not affect any functionality and can be safely ignored.

Quiz generates fewer questions than requested

Small local models (qwen3-4b, gemma-3-4b) can struggle to produce many unique questions from short documents. Try uploading a longer or more detailed document, or reduce the requested question count.

Library disappeared after restarting

Check that data/library.json exists and is not corrupted. If it was deleted (or the data/ folder was wiped), the library will be empty — re-upload your documents.

💡 If something unexpected happens, the terminal window running python app.py shows detailed error logs. Check there first before assuming a feature is broken.
